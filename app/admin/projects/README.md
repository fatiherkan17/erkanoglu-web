# Proje Arşivi Yapısı

Her proje kaydı zaman içinde şu başlıkları taşıyacaktır:

- Genel Bilgiler
- Hizmetler
- Uygulama Projeleri
- İmalat Arşivi
- Fotoğraf Arşivi
- Çözüm Ortakları
- Görüşmeler
- Teklifler

Bu dosya, proje veri yapısının yönünü belgelemek için tutulur. Yönetim panelindeki gerçek arşiv alanları ilerleyen adımlarda ayrı veri modelleriyle bağlanacaktır.
